# DSC630 Data Science Project

**Author:** Allison Evanich

## 🔍 Project Overview

This project demonstrates an end-to-end data science workflow---from
problem definition to model interpretation.\
The goal is not only to build a working model, but to show *why* each
step was chosen and how decisions were made.

------------------------------------------------------------------------

## 🎯 Problem Statement

This project explores how specific features influence outcomes in the
dataset and applies statistical modeling to: - Identify meaningful
predictors\
- Quantify their impact\
- Translate findings into actionable insights

------------------------------------------------------------------------

## 🧭 Project Workflow & Reasoning

### 1. Data Understanding & Exploration

**Why this step?**\
Before modeling, it's critical to understand the structure, scale, and
limitations of the data.\
This prevents misuse of variables and reduces the risk of biased
conclusions.

**What I did:**\
- Reviewed column types and distributions\
- Checked for missing values and outliers\
- Identified variables suitable for modeling

------------------------------------------------------------------------

### 2. Data Cleaning & Preparation

**Why this step?**\
Clean data ensures that results reflect real patterns---not artifacts of
poor formatting or noise.

**What I did:**\
- Handled missing and invalid values\
- Removed non-predictive identifiers\
- Transformed skewed variables (e.g., log transformations) to meet model
assumptions

------------------------------------------------------------------------

### 3. Feature Selection

**Why this step?**\
Reducing unnecessary features improves model interpretability and
prevents overfitting.

**What I did:**\
- Removed columns that introduced leakage or redundancy\
- Retained variables aligned with the research question\
- Ensured predictors were relevant and justifiable

------------------------------------------------------------------------

### 4. Modeling Approach

**Why this model?**\
I selected regression modeling because it: - Provides interpretability\
- Quantifies relationships\
- Supports inference, not just prediction

**What I did:**\
- Built an OLS regression model\
- Evaluated assumptions (linearity, independence, homoscedasticity)\
- Compared performance using R² and adjusted R²

------------------------------------------------------------------------

### 5. Model Evaluation

**Why this step?**\
A model isn't useful unless its results are reliable and explainable.

**What I did:**\
- Interpreted coefficients for real-world meaning\
- Analyzed statistical significance\
- Identified limitations and sources of bias

------------------------------------------------------------------------

### 6. Insights & Business Impact

**Why this step?**\
The value of data science lies in decision-making---not just accuracy.

**What I did:**\
- Translated findings into practical insights\
- Discussed implications for stakeholders\
- Highlighted opportunities for improvement and future modeling
